# Bonney Hold Co — Operations Intelligence

PE-grade operations dashboard for **Bonney Hold Co** — covering all 4 California brands:

- **Bonney** (Sacramento area; HVAC, Plumbing, Sewer/Drain, Electrical)
- **Peter Levi** (HVAC, Plumbing, Electrical)
- **Gallaghers** (HVAC, Plumbing, Electrical)
- **Big Air** (HVAC, Plumbing)

## Data Source

ServiceTitan Brand Reports, May 2023 – May 2026. 239,884 completed jobs / $449M revenue.

## Tabs

1. **Executive Brief** — Hero KPIs (L12M revenue, jobs, avg ticket, all-time) with brand picker
2. **P&L Control Tower** — L12M vs P12M, revenue by trade, monthly jobs trend
3. **Brands** — Per-brand cards (Bonney, Peter Levi, Gallaghers, Big Air) with click-to-filter
4. **Service Lines** — Trade mix doughnut + breakdown table
5. **Job Types** — Drilldown with YoY % + absolute delta + ▲ NEW + ✕ retired rows
6. **Demand Gen** — Campaign category attribution
